# GOAL.md - Stemmagraph v412: Relationship-Based Privacy Fase 1 Filter Relasi Viewer (VISION 0.8 fase 4)

- **Item Aktif:** Stemmagraph v412 fase 1 relationship-based privacy: daftar relasi keluarga yang dibaca viewer tidak lagi membocorkan struktur di sekitar anggota yang hidden baginya; keputusan visibility satu hop ujung relasi diputuskan server-side dengan pasangan modul yang sudah hidup (resolveViewerRelation + applyMemberVisibility, pola v261-i).
- **Tujuan:** VISION 0.8 menuntut alur consent penuh termasuk relationship-based privacy. Single-member GET sudah ter-gate (server/index.ts baris 3740, hidden = 404 bentuk identik anti-enumerasi), tetapi GET /api/v1/trees/:treeId/relationships (baris 4265) masih mengembalikan SELURUH relasi pohon bagi siapa pun yang lolos view_tree, sehingga viewer dapat memetakan topologi keluarga angka hidden walau detailnya tak terbaca. Fase 1 menutup kebocoran baca ini.
- **Pilar / AC (kontrak AC1-AC5):**
  1. AC1: modul pure baru src/lib/privacy/relationshipVisibility.ts: filterRelationshipsForViewer menerima keputusan visibility per member (peta memberId ke full atau hidden, sumber applyMemberVisibility) dan daftar relasi structural; relasi dihilangkan bila SALAH SATU ujungnya hidden bagi viewer tersebut; deterministik, tanpa I/O, tanpa clock, tanpa dependency.
  2. AC2: wiring route GET /api/v1/trees/:treeId/relationships: setelah guard view_tree eksisting, server menghitung visibility set anggota pola v261-i (email User vs FamilyMember.email, resolveViewerRelation reuse apa adanya), memfilter via modul AC1; owner dan editor lolos penuh tanpa filter (peran dari guardTreeAction eksisting); viewer menerima 200 daftar terfilter, TANPA indikator jumlah asli (anti-enumerasi, respons sukses biasa bukan 403).
  3. AC3: reuse add-only: resolveViewerRelation dan applyMemberVisibility tidak diubah; formatRelationship tetap; tanpa perubahan schema, tanpa migrasi, tanpa menyentuh route write relationship.
  4. AC4: test vitest: unit pure filter (relasi dua ujung hidden, campuran full-hidden, daftar kosong, determinisme dua panggilan), test API (owner full list, viewer menerima daftar tereduksi 200 tanpa relasi yang menyentuh member hidden baginya, 401 tanpa auth, 404 tree bukan milik user), regresi kesesuaian keputusan single GET vs list untuk viewer sama.
  5. AC5: gates penuh: prisma validate 0 tanpa migrasi tanpa perubahan schema, tsc 0, lint 0 error (baseline 9 warning), build 0, vitest scope hijau, em dash 0 di baris tambahan, NIHIL dependency baru, pure core terjaga (tanpa kode komersial), scope tanpa file scratch.
- **Non-Goals:** tanpa relasi kerabat N langkah (menunggu model data 0.6 GA, catatan VISION gap #1), tanpa perubahan UI (pola ARIA disclosure dicatat Sena untuk fase UI berikutnya, bukan fase ini), tanpa perubahan write endpoints, tanpa notifikasi baru, tanpa export consent ledger, tanpa main/staging.
