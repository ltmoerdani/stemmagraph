# GOAL.md - Stemmagraph v415: Komentar Profil Fase 1 (VISION Pilar 2 Kolaborasi Keluarga)

- **Item Aktif:** Stemmagraph v415 Komentar Profil Fase 1: backend komentar pada profil anggota (FamilyMember) dengan guard role editor, pagination, dan event store emit; UI menyusul fase 2.
- **Tujuan:** VISION-stemmagraph Pilar 2 menyatakan kolaborasi keluarga menyusul komentar profil. Fondasi kolaborasi sudah matang (TreeMember role, guardTreeAction, MergeApprovalsPanel pola review), tapi anggota tidak punya permukaan komentar, keluarga tidak bisa berdiskusi di profil anggota. Fase 1 membangun API dan data layer, fase 2 UI panel.
- **Spesifikasi (feasibility first-hand PM wake-177):** model FamilyMember hidup (prisma/schema.prisma baris 121, tanpa field komentar), TreeMember role viewer/editor/owner (baris 213), guardTreeAction dipakai semua route proteksi (server/index.ts 1729 pola), pola route REST konsisten /api/v1/trees/:treeId/... dan /api/v1/members/:id (baris 3776), tanpa zod di server (pola validasi manual isTreeRole), MergeApprovals + event store pola emit ada. Skema DILARANG rusak: penambahan model Comment baru add-only dengan migrasi prisma tunggal.
- **Pilar / AC (kontrak AC1-AC6):**
  1. AC1: model prisma add-only: model Comment { id, treeId, memberId (FK FamilyMember onDelete Cascade), userId (FK User onDelete Cascade), body String maks 2000, createdAt, @@index([memberId, createdAt]) }, migrasi prisma tunggal add-only, TANPA mengubah field model existing.
  2. AC2: route POST /api/v1/members/:memberId/comments (requireAuth): guardTreeAction(treeId anggota, 'edit_content'), validasi body string trim 1..2000, respons 201 { comment: { id, memberId, userId, body, createdAt } }, 404 MEMBER_NOT_FOUND, 403 guard code, 400 VALIDATION_ERROR.
  3. AC3: route GET /api/v1/members/:memberId/comments (requireAuth): guardTreeAction(treeId anggota, 'view_tree'), pagination cursor createdAt+id (after param, default 20, maks 50), urut createdAt desc, respons { comments: [...], nextCursor: string|null }, tiap item include user name (tanpa email), 404 MEMBER_NOT_FOUND.
  4. AC4: route DELETE /api/v1/comments/:commentId (requireAuth): hanya penulis comment.userId === req.userId ATAU role owner pohon, 204 nihil body, 404 COMMENT_NOT_FOUND, 403 FORBIDDEN untuk viewer/editor bukan penulis.
  5. AC5: test vitest: API test pola vi.hoisted plus express ephemeral (post: sukses, 400 body kosong, 400 body lebih 2000, 403 viewer, 404; get: pagination 2 halaman, nextCursor null habis, 404; delete: penulis sukses, owner sukses, viewer bukan penulis 403, 404).
  6. AC6: gates penuh: prisma validate 0 plus TEPAT 1 migrasi add-only, tsc 0, lint 0 error (baseline 9 warning), build 0, vitest scope hijau, em dash 0 di baris tambahan, NIHIL dependency baru, pure core terjaga (tanpa kode komersial), scope tanpa file scratch.
- **Non-Goals:** tanpa UI komentar (fase 2), tanpa edit komentar setelah kirim (hapus plus tulis ulang), tanpa reaksi atau mention, tanpa notifikasi email atau digest (fase lanjut), tanpa komentar pada objek lain (families, sources), tanpa moderation admin, tanpa main/staging.
